# F5 手動驗證清單（M3）

自動測試用 `vscode` 的替身，無法證明真實 VS Code 介面的外觀與互動。請在 Extension Development Host（F5）依序確認，打勾後在最下方記錄日期與結果。

準備：`pnpm run build`，按 F5。測試帳號的密碼請只在登入對話框輸入，不要貼到任何檔案。

## 外觀

- [ ] 活動列出現「PTT」圖示，圖示在淺色與深色主題都看得清楚。
- [ ] 點開後看到「看板」檢視，未登入時顯示「登入 PTT」節點。
- [ ] 狀態列左側顯示「PTT 未登入」，點擊跳出選單（登入 / 登出 / 重新連線 / 清除已儲存的帳密）。
- [ ] 命令選擇區（Ctrl+Shift+P）輸入 `PTT` 只看到 login、logout、reconnect、clearCredentials、statusMenu、refresh、clearCache、openBoard、refreshArticle，看不到 loadMore / openArticle / copyArticle*。

## 登入

- [ ] 「PTT: 登入」依序詢問帳號、密碼（密碼輸入為遮蔽）、是否記住（三個選項）。
- [ ] 選「都不記住」登入成功後，狀態列顯示帳號；重新載入視窗後仍需重新輸入。
- [ ] 選「記住帳號和密碼」後重新載入視窗，`vscptt.login.autoLogin` 開啟時會自動登入；關閉時顯示登入節點。
- [ ] 「清除已儲存的帳密」後，再登入會重新詢問。
- [ ] 故意輸入錯誤密碼：顯示可讀的錯誤訊息，狀態列回到未登入，沒有卡住（此情境的 PTT 實際文字尚未實測，若失敗請回報畫面）。
- [ ] 帳號已在別處登入時出現對話框；按關閉或「保留對方連線」不會登出對方；只有按「登出對方並登入」才會。

## 看板與文章

- [ ] 「我的最愛」展開後列出看板；有錯誤時顯示警告節點而不是空白。
- [ ] 「PTT: 開啟看板…」輸入看板名稱，看板出現在「已開啟的看板」，重新載入視窗後仍在。
- [ ] 看板節點展開後最新文章在最上方；置頂文章群組可展開；「載入更多」會接上更舊的文章。
- [ ] 點文章開啟唯讀文件，標題、作者、看板、時間、內文與推文正確；連點不同文章，每次顯示的都是被點的那一篇（A 不會變 B）。
- [ ] 編輯器標題列的重新整理按鈕可重新讀取該文章。
- [ ] 右鍵文章可複製文章代碼與網址，網址格式為 `https://www.ptt.cc/bbs/<看板>/M.<數字>.A.<代碼>.html`。
- [ ] 檢視標題列的重新整理與清除快取按鈕有作用。

## 在瀏覽器開啟

- [ ] 文章右鍵「在瀏覽器開啟文章」會用預設瀏覽器開到 `https://www.ptt.cc/bbs/<看板>/M.<數字>.A.<代碼>.html`。

## 搜尋

- [ ] 看板節點的行內放大鏡按鈕、檢視標題列的放大鏡、命令面板「PTT: 搜尋看板…」都能開始搜尋；從看板節點開始時不再問看板名稱。
- [ ] 依序選「標題關鍵字」「作者」「推文數」各搜一次：輸入框的提示合理，輸入不合格內容（空白、太長、作者含空格、推文數不是整數）時輸入框會擋下並說明原因。
- [ ] 有結果時樹狀檢視多出「搜尋結果」群組，每組一個節點（例：`Soft_Job：標題「人月」`），結果新到舊；「載入更多」會接上更舊的結果。
- [ ] 點搜尋結果的文章，開到的是被點的那一篇；連續點不同的結果也沒有 A 變 B。
- [ ] 搜尋沒有結果時只出現「沒有符合的文章」，樹狀檢視沒有多出空的搜尋。
- [ ] 搜完之後再展開同一個看板的一般文章列表，內容和之前一樣（沒有停在搜尋模式）。
- [ ] 同一組搜尋再搜一次不會重複出現；搜尋超過上限（設定 `vscptt.search.maxSaved`）時最舊的被移除；節點的 X 按鈕可移除一組搜尋。
- [ ] 登出後再登入，「搜尋結果」群組已清空。
- [ ] 把 `vscptt.article.maxPages` 改成 1，重新登入後開一篇長文：只讀第一個畫面，文章開頭註明內容被截斷。

## 登出與中斷

- [ ] 「PTT: 登出」後狀態列回到未登入，樹狀檢視回到登入節點；PTT 端沒有殘留「重複登入」提示（再登入一次確認）。
- [ ] 登入中直接關閉整個視窗，再次登入沒有重複登入提示（`deactivate` 有禮貌登出；若出現請回報）。
- [ ] 中斷網路後狀態列顯示中斷並有通知；不會自動重連，使用「重新連線」可恢復。
